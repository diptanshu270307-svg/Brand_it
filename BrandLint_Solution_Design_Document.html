01 Problem Statement & Solution Overview

Brands spend hundreds of millions creating high-velocity digital ads across Meta, TikTok, LinkedIn, display networks, and print packaging. However, up to 18% of campaign budget is lost due to three catastrophic bottlenecks:

1. Unsubstantiated & Expired Claims

Marketers inadvertently publish superlatives ("100% Guaranteed", "#1 Doctor Recommended") lacking clinical proof. When clinical studies expire, brands face FTC fines and manual retrospective audits.

2. Platform Safe-Zone & WCAG Rejections

Creatives are rejected by ad networks due to text density exceeding platform limits (Meta 20% rule) or critical CTAs colliding with platform interface elements (Instagram Story headers, TikTok swipe-up buttons).

3. The Legal Review Bottleneck

Human legal review takes 2–3 weeks per campaign cycle. High-velocity creative teams either stall product releases or bypass compliance entirely, exposing the enterprise to severe regulatory risk.

4. LLM Hallucinations & Injection Vulnerabilities

Generic AI checkers hallucinate compliance, cannot measure spatial pixel layout or WCAG contrast, and are vulnerable to prompt injections embedded in uploaded partner documents.

The Solution: BrandLint
An automated, multimodal creative governance pre-flight engine that verifies every ad claim against cryptographic evidence passports and validates image layout before public launch.

02 System & Technical Architecture

BrandLint is engineered as an asynchronous, microservice-based architecture ensuring strict non-blocking I/O for heavy PDF and multimodal image analysis while guaranteeing absolute determinism.

Subsystem Architectural Implementation Enterprise Advantage
Client Application Tier React 18, TypeScript, Tailwind CSS, Vite v5.4. Custom Lustro dark design tokens with zero-overhead utility classes. Sub-140kB production bundle; embedded directly into Figma plugins and browser extensions.
Core API Gateway FastAPI ASGI framework running on Python 3.11+ / Uvicorn. Native asynchronous coroutine orchestration. Sub-50ms API request latency. Handles concurrent batch image OCR without thread starvation.
Document Ingestion & Quarantine PyMuPDF (fitz) + pdfplumber + UTF-8 character byte-offset normalization engine. Strips embedded prompt injections and malicious instruction overrides from uploaded PDFs before parsing.
Multimodal Vision & Placement Engine OpenCV + Pillow image processing + local OCR engine. Calculates 3×3 rule-of-thirds density and W3C WCAG 2.1 contrast math. Zero-latency local processing. Automatically detects safe-zone violations across 16:9, 9:16, 4:5, 1:1, and packaging aspect ratios.
Tamper-Evident Evidence Vault SHA-256 cryptographic document fingerprinting. Dynamic passport lifecycle expiration triggers. If a clinical trial expires or is retracted, BrandLint automatically flags all historically approved drafts with recall warnings.
Dual Control Security Gate Four-eyes authorization model enforced at database constraint level (author_id != reviewer_id). Eliminates self-approval loopholes, ensuring rigorous compliance for SOX, FDA, and FTC auditing.
